【我把 1.75 GB 工作資料交給 AI agent 刪掉了，靠 Windows 快照救回來】

2026-11-16，我用桌面 AI agent（full access）測試自製的卸載腳本，測試值給了 `-Dest "C:\"`。腳本的防護沒處理尾端分隔符，`C:\` 一路通過檢查，接著 `cmd /c rd /s /q "C:\"` 開始跑——約 2–3 分鐘後我中止它，工作資料夾已經不見：1,372 個檔案、143 個目錄、1.744 GB。

為什麼沒有第二層擋住？

・full access 模式不逐次詢問，工具呼叫直接執行。
・刪除動詞在腳本檔案裡，shell 工具只看得到「執行 uninstall.ps1」。
・那個「自動授權審查」機制預設是關的。
・我拿真實資料路徑測試「刪除保護」，這是最該檢討的一步。

怎麼救回來的？同一台機器 13:16 的 VSS 影子複本還在。掛載影子磁碟區後用 robocopy 還原，核對結果 143 目錄 / 1,372 檔案 / 1.744 GB、0 FAILED，與快照完全一致。真正失去的是快照之後、事發之前新建的內容。

給正在用 AI agent 的人 5 件事：
1. 開系統保護，並實際確認 `vssadmin list shadows` 有還原點。
2. 重要資料要有外接或雲端備份，且定期還原驗證。
3. agent 不要給管理員權限，full access 只短暫開啟。
4. 破壞性操作先 dry-run、先列出將刪除清單。
5. 把高危操作守則寫進全域 `AGENTS.md`。

開發者的一句話：路徑防護要做在工具層，不可逆操作要批准、刪前要有還原點。快照不是備份，備份是唯一保險。
